BALLAST — A Weight-Thief's Tale: a mass-transfer puzzle platformer. Steal weight from crates, boulders, golems and mines into a 0–3 gauge and give it back: light floats, heavy smashes. 9 hand-built rooms, 27 stars, combos, and a vault to open.

v4 is a density and readability pass over v3 (same 9 rooms, same difficulty curve, same mechanics): a sunlit vault so every platform and entity reads in a still frame, one extra boulder in rooms 2, 3 and 7, floor props, wall murals and lanterns, a persistent tether beam from Pip to the next transfer target, a room-roster strip in the HUD (golems, mines, orbs, weight on hand, gate state), and a title screen with a live gameplay vignette and a nine-room inventory.

## Run it

```sh
node serve.ts
```
