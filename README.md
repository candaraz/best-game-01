BALLAST — A Weight-Thief's Tale. A puzzle-action platformer whose whole identity is mass transfer: steal weight from crates, boulders, golems and mines into a 0–3 gauge, give it back, and watch what Pip weighs change everything — floaty at gauge 0, an anchor at gauge 3. 8 hand-built rooms, 3 stars each, all art drawn in code and all sound synthesized in the browser. Vanilla canvas, no libraries, fully offline.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Or serve `game/` with any static HTTP server and open `game/index.html`. To build the submission dossier: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
